# YOSHRUN — Main Lobby & Visual Experience

**Version:** 0.1 — approved visual target
**Reference:** The cinematic YOSHRUN mobile lobby concept approved in the conversation on 2026-11-26.

## Visual identity
The approved direction is a premium mobile battle-royale presentation: cinematic 3D environment, confident hero lineup, strong readable silhouettes, rich but controlled colour, dramatic portal lighting, and compact high-contrast touch UI. This is a visual-quality target, not a reproduction of another game's protected assets or interface.

## Main lobby composition
- Landscape 16:9 phone layout.
- Background: monumental YOSHRUN stone gate and glowing blue portal, maze architecture, watchtowers, vegetation, distant aircraft / traversal silhouettes and atmospheric depth.
- Foreground: four original playable heroes in a full-body squad presentation. The selected hero stands in the central foreground; companions flank them. A summoned-creature companion may appear beside the squad as a preview.
- Top bar: player portrait, username, level, coins, gems, inbox, friends, settings and connection state.
- Left navigation: Store, Lucky Draw, Characters, Vault, Weapons, Summons, Missions and Events.
- Right mode cards: MAZE ROYALE and MAZE CLASH (5v5), plus Daily Missions, Rewards and Season Rank.
- Bottom navigation: Settings, Rankings, Community and Maps.
- Bottom-right: selected mode summary and large primary Play button.
- Chat / party status remains visible without covering character faces or the primary action.

## Character roster presentation
- RAYAN: central default hero / Pathfinder, charcoal and teal survival jacket, forearm maze-map device.
- LINA: medic, sand and red field-medical kit, practical silhouette.
- KADIR: mechanic, dark workwear, copper hardware and tool harness.
- NOUR: scout, slate-blue lightweight gear and acoustic headset.
- THE WARDEN and SABLE are selectable hunter characters for the appropriate modes.
All faces, clothing, logos, weapons, pets and animations must be original YOSHRUN creations.

## Interaction behaviour
- Tapping a character opens a full-body preview, biography, role and ability details.
- Tapping a mode card selects the mode and updates the mode summary.
- Play opens matchmaking / solo preparation for the selected mode.
- Currency buttons open the relevant earn / purchase screen; currency is not spent merely by previewing.
- Store, inventory, missions, friends, inbox and settings each open their own screen.
- UI must support safe areas, different aspect ratios, scalable text and touch targets.

## Production asset requirements
1. Approved front / side / back character concept sheets.
2. Production-ready 3D hero meshes, PBR materials, humanoid rigs and animation sets.
3. Modular lobby environment and portal VFX.
4. Original creature companion models and animation.
5. UI icon set, typography, button states, panels and localization.
6. Optimized texture atlases, LODs and mobile VFX tiers.

## Implementation order
1. Build the responsive lobby layout and navigation with temporary assets.
2. Add character selection and animated 3D preview.
3. Replace temporary character shapes with approved original 3D assets.
4. Add mode selection and pre-match flow.
5. Connect store, inventory, missions, party and online services.
6. Profile and test on low-, mid- and high-tier Android devices.

## Accuracy / status
The approved concept image is a visual target. It is not an in-game screenshot and does not mean that the 3D models, lobby, online systems or APK are already complete. The repository must report each implemented and tested milestone accurately.
